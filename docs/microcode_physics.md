# Microcode Physics

- 00 — Passive collapse / write‑if‑empty
- 01 — Forced overwrite
- 11 — Protected history / hold

## Behaviors

- neighbor healing
- temporal shock propagation
- global reset phase transitions

These rules define the “physics” of the memory universe.
