# ToroidalStateEngine — Architectural Overview

The ToroidalStateEngine is a unified memory‑process substrate where
geometry, state evolution, and rule‑zones replace traditional CPU
execution. This document provides a conceptual overview of the system.

## Core Principles
- Memory = Processor = Process
- Geometry schedules execution
- Local rules behave like microcode physics
- State evolves through overwrite waves and attractors

## Why a Torus?
A torus provides:
- recurrence
- locality
- no boundaries
- stable attractors
- vortex‑like propagation

This geometry replaces the instruction pointer with a circulating ring index.
